# Decisões

Esta pasta recebe decisões duráveis que alterem princípios, estrutura, taxonomia ou políticas do SKF.

Cada decisão deve registrar:

- contexto;
- decisão;
- alternativas consideradas;
- consequências;
- estado;
- data;
- documentos afetados.

O formato preferencial é `SKF-ADR-NNNN-titulo.md`.

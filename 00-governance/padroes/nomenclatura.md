# Padrão de Nomenclatura

## Identificação

- Código: `SKF-STD-NOME-001`
- Versão: `1.0.0`
- Estado: proposto para a Foundation v1.0

## Regras gerais

Nomes técnicos de arquivos e diretórios devem:

- usar letras minúsculas;
- usar caracteres ASCII;
- separar palavras com hífen;
- evitar espaços;
- evitar acentos;
- evitar abreviações ambíguas;
- manter a extensão original do arquivo.

Exemplo:

```text
mec-api-0001-cartilha-uso-api-gestao-presente.pdf
```

## Exceção para identificadores

Identificadores permanentes podem usar letras maiúsculas e hífens:

```text
MEC-API-0001
SKF-0000
RF-MEC-API-0001-001
```

Quando o identificador nomear a pasta de um dossiê ou de uma fonte, deve permanecer em sua forma canônica.

## Títulos humanos

Títulos dentro dos documentos devem preservar ortografia, acentuação e terminologia oficial.

## Fontes originais

O nome físico pode ser normalizado para portabilidade. O título original deve ser preservado no catálogo e na ficha técnica.

## Datas

Quando necessárias em nomes, usar:

```text
AAAA-MM-DD
```

## Versões

Usar `v` seguido da versão quando fizer parte do nome:

```text
relatorio-homologacao-v1.0.0.md
```

Não usar expressões vagas como `final`, `final-2`, `novo` ou `atualizado`.

## Arquivos Markdown

Preferir nomes descritivos:

```text
estrutura-repositorio.md
citacoes-e-fontes.md
```

Dentro de dossiês numerados, usar dois dígitos:

```text
00-ficha-tecnica.md
01-resumo-executivo.md
```

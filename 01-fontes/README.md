# Fontes

Esta área preserva os documentos, arquivos e referências utilizados como origem do conhecimento.

## Regras

1. A fonte deve receber um identificador permanente.
2. O arquivo original não deve ser alterado.
3. Renomeações devem preservar extensão e integridade.
4. O checksum SHA-256 deve constar no catálogo.
5. Análises não devem ser armazenadas nesta área.
6. Dados sensíveis ou restritos não devem ser publicados sem autorização.

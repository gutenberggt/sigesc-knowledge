# Dossiês

Cada fonte relevante pode gerar um dossiê analítico próprio.

O dossiê reúne, conforme aplicável:

- ficha técnica;
- resumo;
- glossário;
- regras e restrições;
- requisitos;
- casos de uso;
- fluxos;
- modelos;
- impactos;
- gaps;
- oportunidades;
- rastreabilidade;
- notas e pendências.

O conteúdo de um dossiê ainda pode conter hipóteses, propostas e pontos a confirmar.

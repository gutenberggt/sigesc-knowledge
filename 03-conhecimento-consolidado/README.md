# Conhecimento Consolidado

Esta área contém apenas conhecimento revisado, validado e reutilizável entre múltiplos dossiês ou módulos.

Não se deve copiar automaticamente todo conteúdo produzido nos dossiês.

A promoção para esta camada exige:

- revisão;
- eliminação de duplicidades;
- identificação da fonte;
- resolução das principais ambiguidades;
- definição do estado de validade.
